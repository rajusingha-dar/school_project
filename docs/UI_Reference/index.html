The problem

Report cards tell you what already happened. Nothing tells you what's happening now.

Exam-time signals only

Marks hide the "why"

A 62% doesn't say whether the trouble is fractions, careless mistakes, or reading the question wrong.

No continuous view for schools

Teachers manage 30+ students with nothing between exams to flag who's quietly falling behind.
